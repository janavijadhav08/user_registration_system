# User Registration Management System

A simple web-based user registration application developed using Python, Streamlit, and PostgreSQL.

## Features

* User registration form
* Collects user details such as name, email, phone, age, and gender
* Form validation
* Stores user data in PostgreSQL database
* Interactive user interface using Streamlit

## Technologies Used

* Python
* Streamlit
* PostgreSQL
* Psycopg2

## How to Run

1. Install the required libraries:

pip install -r requirements.txt

2. Configure the PostgreSQL database.

3. Run the application:

streamlit run app.py
